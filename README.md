## Installation

The Python package `PLACEHOLDER` can be installed from PyPI:

```
python -m pip install PLACEHOLDER
```

## Development installation

If you want to contribute to the development of `PLACEHOLDER`, we recommend
the following editable installation from this repository:

```
python -m pip install --editable .[tests]
```

Having done so, the test suite can be run using `pytest`:

```
python -m pytest
```
